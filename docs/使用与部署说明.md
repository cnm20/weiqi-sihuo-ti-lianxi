# 使用与部署说明

## 本机使用

```bash
npm install
npm run dev
# 打开浏览器访问 http://localhost:5173（以终端提示为准）
```

手机与本机联调：同一局域网内，手机访问开发机 IP + 端口。
注意：**局域网 HTTP 仅用于普通页面联调**；PWA 安装与离线功能要求 HTTPS 或 localhost。

## 部署到 HTTPS 静态托管

```bash
npm run build
# dist/ 即为可部署产物
```

将 `dist/` 整体上传到任意 HTTPS 静态托管（GitHub Pages、Netlify、Vercel、自有服务器等）即可。

## 离线（PWA）

- 应用使用 `vite-plugin-pwa`（generateSW）。
- 首次加载会缓存应用外壳、全部 100 题数据与反馈图片等静态资源，并显示“已可离线使用”。
- 缓存完成后断网/飞行模式打开页面即可继续做题。
- 更新：发布新版本后，旧客户端提示“发现新版本”，由用户点“立即更新”；不打断进行中的挑战。
- PWA 安装需满足：HTTPS（或 localhost）、有效 manifest 与图标、可用的 service worker。

## 数据与隐私

- 进度与未完成挑战保存在浏览器 `localStorage`，不会上传。
- 手机与电脑各自保存，无账号、无自动同步。

## 常见问题

- 切后台再回来剩余时间没减少 = 正常（仅累计前台时间）。
- 刷新后棋盘恢复 = 进行中的挑战已自动保存，返回时继续。
- 提示“此变化暂未收录” = 该合法着法不在已审核答案树中，本次不计成绩（可查看解答或重试）。
